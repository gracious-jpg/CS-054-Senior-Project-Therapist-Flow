
# TherapistFlow – Project Overview and Setup Guide

A burnout prevention and workload management application for therapists and supervisors.

## Project Overview

TherapistFlow is a senior software engineering capstone project developed by Team 54 at Oregon State University.

The goal of this project is to help therapists better manage their workload, monitor stress, and reduce the risk of burnout. Therapists often manage multiple clients, appointments, and responsibilities, which can become overwhelming. TherapistFlow aims to provide a simple way to track workload and personal well-being in one place.

Our team is working with a project sponsor to understand the needs of therapists and develop a useful and easy-to-use application.

## Planned Features

The application is expected to include the following features:

- **Mood Tracking:** Allow therapists to record their mood and monitor changes over time.
- **Session Logging:** Allow therapists to record and organize their therapy sessions.
- **Workload Analysis:** Help therapists understand their workload and identify possible signs of stress or burnout.
- **Scheduling Support:** Help therapists organize their schedules and manage their responsibilities.
- **Supervisor Support:** Explore ways supervisors can better understand and support therapist workloads.

Additional features, including notifications and AI-generated recommendations, are still being discussed with the project sponsor.

These features are planned and should not be considered implemented until they are available and tested.

## Getting Started

### Prerequisites

To access and work with the repository, you will need:

- Git installed on your computer.
- A code editor, such as Visual Studio Code.
- Access to the project's GitHub repository.

Additional software and dependencies will be documented once the development framework and starter application are available.

### Installation

1. Open a terminal or command prompt.

2. Clone the GitHub repository:

```bash
git clone https://github.com/gracious-jpg/CS-054-Senior-Project-Therapist-Flow.git
```

3. Navigate into the project directory:

```bash
cd CS-054-Senior-Project-Therapist-Flow
```

4. Open the project in your preferred code editor.

The repository can now be viewed and edited locally.
